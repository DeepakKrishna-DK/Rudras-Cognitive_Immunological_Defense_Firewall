# Glossary and Abbreviations

| Acronym | Full Form | Definition |
|---------|-----------|------------|
| APT | Advanced Persistent Threat | An adversary equipped with sophisticated levels of expertise and significant resources that allow them to create opportunities to achieve their objectives. |
| BYOD | Bring Your Own Device | An enterprise policy enabling employees to use their personal devices to access corporate networks. |
| C2 | Command and Control | Infrastructure used by attackers to maintain communication with compromised devices. |
| CIDS | Cognitive Immunological Defense System | Rudras's core system model designed to proactively catch unknown threats via continuous behavioral observation. |
| DPI | Deep Packet Inspection | Advanced packet filtering that examines data parts of a network packet for non-compliance, spam, and malware. |
| DLP | Data Loss Prevention | Strategies and tools to prevent unauthorized access or sharing of sensitive data. |
| eBPF | Extended Berkeley Packet Filter | A technology allowing for programmability within the OS kernel without adding kernel modules. |
| GNN | Graph Neural Network | A class of artificial neural networks that process data represented by graphs. Used by Rudras for topology analysis. |
| L2–L7 | Layers 2 through 7 | Layers of the OSI network model, ranging from Data Link (L2) to Application (L7). |
| MTD | Moving Target Defense | A mechanism to dynamically change a system's attack surface to increase uncertainty and complexity for attackers. |
| P4 | Programming Protocol-independent Packet Processors | A domain-specific language used for expressing how packets are processed by the data plane of a network forwarder. |
| PQC | Post-Quantum Cryptography | Cryptographic algorithms thought to be secure against an attack by a quantum computer. |
| SBOM | Software Bill of Materials | A comprehensively structured list of components, libraries, and modules required to build a piece of software. |
| SLSA | Supply-chain Levels for Software Artifacts | A security framework intended to prevent tampering, improve integrity, and secure packages and infrastructure. |
| SIEM | Security Information and Event Management | A system that provides a holistic view of an organization's IT security, merging security information management and security event management into a unified system. |
| SOAR | Security Orchestration, Automation, and Response | Technologies that enable organizations to collect security threats data and automated responses. |
| TLS | Transport Layer Security | A cryptographic protocol designed to provide communications security over a computer network. |
| TPM | Trusted Platform Module | A specialized chip on an endpoint device that stores RSA encryption keys specific to the host system. |
| UEBA | User and Entity Behavior Analytics | Solutions that use analytics and machine learning to detect anomalous behaviors from users, devices, and applications. |
| WAF | Web Application Firewall | A specific form of application firewall that filters, monitors, and blocks HTTP traffic to and from a web application. |
| XDP | eXpress Data Path | A Linux kernel feature providing a high-performance, programmable network data path. |
